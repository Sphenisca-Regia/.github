# Security

Found a vulnerability in anything under Sphenisca-Regia? Report it privately:
open the repo's **Security** tab and choose **Report a vulnerability**. Don't
open a public issue.

Include what's affected (app and version or commit), how to reproduce it, and
what an attacker gets. You'll get a reply within a week. Fixes ship in the open
once they're ready, with credit unless you'd rather not.

Only the latest `main` of each repo is supported.
